# لوحة تحكم المسير — Next.js

هذه لوحة تحكم مخصصة **للمسير فقط** (حسابك الشخصي بدور `admin` في قاعدة
البيانات). لا يوجد أي مسار في التطبيق يسمح لأي مستخدم آخر بالوصول
إليها أو ترقية نفسه لدور admin.

## التشغيل
```bash
npm install
cp .env.local.example .env.local   # عدّل NEXT_PUBLIC_API_URL لعنوان خادمك الفعلي
npm run dev
```
يفتح على `http://localhost:3000`

## الصفحات
- **نظرة عامة**: إحصائيات سريعة (عدد المستخدمين، طلبات توثيق معلّقة، غرف نشطة، محظورون)
- **مراجعة التوثيق**: عرض كل طلبات KYC المعلّقة (بطاقة تعريف/جواز/صورة حية)، مع موافقة أو رفض يدوي. الموافقة تشترط إدخال تاريخ الميلاد المستخرج من الوثيقة، والنظام يرفض تلقائيًا أي عمر أقل من 18 عامًا
- **المستخدمون والحظر**: حظر بالهاتف/الإيميل أو بعنوان IP كامل، مع إلغاء الحظر
- **الغرف**: عرض كل الغرف النشطة وإمكانية حظر أي غرفة مخالفة
- **سجل التدقيق**: كل حركة عملات حدثت في التطبيق لكل المستخدمين، غير قابل للتعديل

## أمان (يجب إكمالها قبل الإنتاج الفعلي)
1. **2FA إجباري**: أضف مصادقة ثنائية على مستوى حساب المسير نفسه — هذه
   الواجهة حاليًا تعتمد فقط على كلمة مرور + JWT، وهو غير كافٍ لصلاحيات
   بهذه الحساسية (حظر، توثيق هوية، اطلاع على بيانات مالية).
2. **لا تنشر هذه اللوحة على نطاق عام** بدون طبقة حماية إضافية (مثل
   IP allowlist أو VPN)، فهي تصل مباشرة لبيانات حساسة جدًا (وثائق هوية).
3. حاليًا الرمز (JWT) يُخزَّن في `localStorage`، وهذا مقبول لأداة داخلية
   يستخدمها شخص واحد فقط، لكن فكّر باستخدام httpOnly cookies إن وسّعت
   لاحقًا الوصول لأكثر من مسير واحد.
4. لعرض صور وثائق الهوية فعليًا (حاليًا يظهر فقط مسار الملف كنص)، اربط
   `storageKey` برابط عرض موقّع قصير الصلاحية (signed URL) من التخزين
   السحابي، ولا تجعل هذه الروابط عامة أبدًا.
