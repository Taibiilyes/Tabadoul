# نسخة سطح المكتب — Tauri

غلاف سطح مكتب خفيف (Windows / macOS / Linux) يعرض واجهة الويب الخاصة
بالمستخدمين مباشرة داخل نافذة تطبيق مستقلة، بدل تكرار بناء كل الواجهة
من الصفر. حجم الملف النهائي عادة 3-10 ميجابايت فقط (مقارنة بـ +150 ميجا
لأي حل مبني على Electron)، لأنه يستخدم محرك العرض المدمج في نظام التشغيل
نفسه بدل تضمين متصفح كامل.

## ⚠️ متطلب أساسي قبل أي شيء
عدّل الرابط `https://app.yourapp.com` في `src-tauri/tauri.conf.json`
(مكانين: `build.frontendDist` و `app.windows[0].url`) ليشير لعنوان
واجهة الويب الفعلية بعد نشرها. بدون هذا التعديل التطبيق لن يعرض شيئًا.

## المتطلبات للبناء محليًا (على جهازك، وليس هنا)
هذا المشروع يتطلب مترجم Rust، وهو غير متوفر في بيئة العمل التي بنيت
بها هذا الكود، لذا لم أتمكن من تجربة الترجمة الفعلية — تحقق من عملها
بنفسك بعد تحميلها بالخطوات التالية:

```bash
# 1. ثبّت Rust (مرة واحدة فقط على جهازك)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# على ويندوز: نزّل rustup-init.exe من https://rustup.rs

# 2. ثبّت حزم Node
npm install

# 3. شغّل التطبيق في وضع التطوير
npm run dev

# 4. لبناء ملف تثبيت جاهز (exe/dmg/AppImage حسب نظامك)
npm run build
```
ستجد ملف التثبيت النهائي في `src-tauri/target/release/bundle/`.

## أيقونة التطبيق
لم أُدرج أيقونة فعلية. بعد تجهيز شعار التطبيق (ملف PNG مربع 1024×1024
على الأقل)، ولّد كل صيغ الأيقونات المطلوبة تلقائيًا بأمر واحد:
```bash
npx tauri icon path/to/your-logo.png
```

## البناء لكل الأنظمة (Windows/macOS/Linux) من جهاز واحد
Tauri لا يدعم البناء المتقاطع (cross-compilation) بسهولة لكل الأنظمة من
جهاز واحد محليًا. الحل العملي: استخدم GitHub Actions (مجاني للمشاريع)
لبناء نسخة Windows وmacOS وLinux تلقائيًا من نفس الكود على خوادم
GitHub. أخبرني إذا أردت أن أجهّز لك ملف `.github/workflows/build.yml`
لهذا الغرض.
